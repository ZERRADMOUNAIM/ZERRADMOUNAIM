# 💫 About Me:
I'm a Data & AI Engineer based in Rabat, Morocco (ENSAM Rabat). I build reliable data systems first — ingestion, modelling, orchestration and data quality — and put useful GenAI on top: RAG, LLM agents and apps that actually work in production. Pipelines first, GenAI second, never decorative.

Currently building: a data pipeline MVP (Airflow + PostgreSQL), a Power BI business dashboard, and a production RAG app — each shipped with code, architecture and trade-offs. Open to Data Engineer / Data & AI Engineer roles in Morocco.

## 🔭 Currently building — Sprint Data Engineer + GenAI (Oct–Dec 2026)

- **A — Data pipeline MVP:** ingestion → star schema → idempotent Airflow DAG → data-quality tests → PostgreSQL
- **B — Power BI dashboard:** 3 pages, DAX, Power Query, built on the pipeline data
- **C — Production RAG app:** embeddings → vector search → FastAPI → evaluation → Docker

> Each project ships with a README: architecture, trade-offs, and how to run it. No demo without code.

## 💼 Featured work

- **Circet Morocco — AI dispatching platform (PFE, 2025):** Airflow + Kafka + PostgreSQL pipeline, XGBoost recommendation, LangGraph + LLM conversational assistant for data queries and reports.
- **Winova, London (remote, 2024):** NLP pipeline for financial documents (Transformers, BERT, DistilBERT via Hugging Face), deployed on GCP with Airflow / Cloud Composer.
- **rag:** retrieval-augmented generation experiments.
- **ETL_Jobs_Salaries:** ETL work on job-market salary data.
